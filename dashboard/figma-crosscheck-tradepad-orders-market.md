## Notes

1. **Sub-screens collapsed:** Multiple Figma frames representing steps within the same user flow (e.g., order summary, OTP, amount entry) are collapsed to a single feature match.
2. **Web variants:** Web versions of mobile trading flows map to the same feature ID (e.g., Saudi Market Trade Web = SAU-001).
3. **Cross-journey features:** Deposit/Transfer maps to XJ-011 (GCC Cash-Out), News to XJ-006, Economic Calendar to XJ-005, Stock Stories to XJ-023.
4. **Trending Tickers:** Maps to US-009 but also relevant to SAU-018 (Top Trending Stocks). Listed under US-009 as primary.
5. **Saudi Options:** List/Filters map to SAU-049 (Saudi Options Native); Trading pages map to SAU-012 (Derivatives Options Trading).
6. **Market file is large:** Contains sections for Saudi, US, UAE, Mutual Fund, Crowd Fund, Robo -- many cross-journey capabilities live here.
7. **Analyst Ratings & Earnings Calendar:** These are SAU-076 and US-028 (figma_file=Watchlist) but also appear in the Market file. Listed as MATCH-LINKED since they already have figma_link from the Watchlist file.
8. **No xlsx or view changes made** -- this is a report-only cross-check.
