## What This Document Is

The ARC Features Map is the authoritative reference for every feature in the ARC platform — catalogued by squad, live status, BRD documentation, and competitive position. It is the primary input for roadmap prioritization, platform maturity scoring, and squad alignment.

**This document is updated:**
- After each major release (live status changes)
- Quarterly (competitive gap review)
- After squad lead validation cycles
