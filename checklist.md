# Checklist — Features Map

## Phase 1 — Discovery & Cataloguing
- [ ] Extract all feature names from live ARC app — screen by screen, flow by flow
- [ ] Review all BRDs in `assets/BRDs/` — log each feature mentioned with BRD reference
- [ ] Map features to the 10 product experience squads
- [ ] Identify features present in competitor apps but absent in ARC — mark as gap
- [ ] Identify ARC features not found in any competitor — mark as differentiator
- [ ] Pull App Store reviews referencing specific features — flag most-mentioned names

## Phase 2 — Classify & Prioritize
- [ ] Build features map table: feature name, squad, journey, live (Y/N), competitor gap, investor demand
- [ ] Score each gap feature: investor demand × competitive pressure = priority score
- [ ] Group features into clusters: trading, portfolio, discovery, engagement, servicing
- [ ] Validate feature list with squad leads — confirm ownership and live status
- [ ] Identify quick-win gaps (low effort, high demand) — flag for next roadmap cycle
- [ ] Present features map to Ahmed for roadmap input session

## Phase 3 — Govern & Update
- [ ] Publish features map as living document — accessible to all squads
- [ ] Update after each app release — add new features, mark shipped gaps
- [ ] Use features map as input to platform-maturity scoring
- [ ] Cross-reference with product-clarity-map to ensure alignment
- [ ] Review quarterly — deprecate removed features, refresh competitor gaps
